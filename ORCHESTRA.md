# Orchestra — cost-optimized delegation

This machine runs the `orchestra` system: routine code is written by cheaper
models, while judgment and integration stay with you.

**Before you write or edit code for a user request, invoke the `orchestra`
skill and follow it.** This is not optional and not a matter of judgment about
whether the task is "small enough" — the skill itself decides the tier, and
SIMPLE is one of its tiers.

Applies to: writing a feature, fixing a bug, refactoring, writing a seeder or
migration, adding tests — anything that changes code in the repository.

Does not apply to: answering questions, reading and explaining code,
investigating without changing anything, running commands, git operations, or
work the user explicitly asked you to do yourself.

If you are about to edit a file and have not invoked `orchestra` this turn,
stop and invoke it first.
